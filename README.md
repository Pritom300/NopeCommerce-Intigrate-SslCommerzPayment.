A fully functional SSLCommerz payment gateway plugin for nopCommerce.  
This plugin enables secure online transactions in Bangladesh through SSLCommerz,  
supporting sandbox and live modes with customer, order, and product integration.  

✨ Features:
- Easy integration with nopCommerce checkout
- Sandbox & live environment support
- Automatic redirection to SSLCommerz payment gateway
- Captures order, customer, and product details
- Configurable from nopCommerce admin panel
- Install & Uninstall support

🔧 Compatible with: nopCommerce 4.80.9
